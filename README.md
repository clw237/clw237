## What I'm working on

- 🧰 **[claude-starter](https://github.com/clw237/claude-starter)**: a small, language-agnostic
  template for projects built with Claude Code. It's set up so you plan before coding, test as you
  go, and use one check script that Claude, you and CI all share. Branch rules, a secret scan and
  an enforced changelog are included. [Why each practice exists →](https://github.com/clw237/claude-starter/blob/main/docs/PRACTICES.md)
- 🃏 **A Commander deck manager**: a personal web app (FastAPI, React, Postgres) for managing and
  upgrading Magic: The Gathering Commander decks. It's where most of claude-starter's practices
  were learned the hard way.

## How I like to work

- **One definition of done.** If the check is green and I've read the diff, it's done. Not before.
- **Guardrails over reminders.** Rules that matter are permissions, hooks or CI checks, not hopes.
- **Small steps.** Test-first slices, each one committed green, so any step is easy to review or undo.
- **Write down the why.** Short decision records, so "why is it like this?" has an answer later.
